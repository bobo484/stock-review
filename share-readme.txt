STOCK REVIEW — how to open

Do this on the company server (the same machine where you opened this Z: folder).

1. Double-click  START STOCK REVIEW.cmd
2. Wait. It copies to this computer, then your browser should open.
3. Leave the black window open while you use it.

If the browser does not open, in Edge or Chrome on THIS same screen type:
   http://localhost:5174/?code=SS-DS24

Do not use that link on your own office PC. localhost only works
on the computer that ran START STOCK REVIEW.

If Windows says it protected your PC: More info → Run anyway.
